Chatterbox TTS Server needs more memory

This service has less memory or disk than the Chatterbox model needs, so the model was not loaded.

Chatterbox-Turbo needs about 4 GB of RAM and about 3 GB of volume space for its model files. That means a Railway Hobby plan or higher: the Free and Trial plans allow 0.5 GB per service.

Raise the service's memory limit (Settings, Resource limits) and the volume size if needed, then redeploy. The model downloads once into the volume and starts automatically.
